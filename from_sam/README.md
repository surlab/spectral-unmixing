## Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/sam-sooter/3color.git
   cd 3color
   ```
2. Create the environment:
   ```bash
   conda env create -f environment.yml
   conda activate 3color
   ```
3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
4. Select the Python (3color) kernel.
